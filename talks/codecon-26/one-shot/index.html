THE INPUT

Original prompt

This is the session's first and only user prompt. Text is preserved as written.

USER PROMPTONE INPUT
Build a native extension, plugin or hook that intercepts large or bulk reads (via read tool) of calling agent and suggests delegation to cheaper sub-agent(s). Delegation inputs are searching scope (files, glob), reason for search and acceptance criteria of valid answer.The operation must be blocking until answer provided. Please, make no mistakes.

SCOPE AND CONTEXT

What “one-shot” means here

One starting prompt

One-shot means this implementation began with the single prompt above. It does not mean the extension handles only one read. The session still contains the agent's work after that prompt.

Related to CC Shunt, not proven equivalent

Both projects address broad reads by routing scoped search to a helper and waiting for a result. CC Shunt uses read hooks and Scout or worker routes across several coding harnesses. One-shot-shunt is a native Pi extension with a scoped delegation tool and acceptance checks.

They are related experiments. This page does not claim the same implementation, proven equivalence, or comparable performance.
