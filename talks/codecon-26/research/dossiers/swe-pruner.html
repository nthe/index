Product research note · survey snapshot 14 Nov 2026

SWE-Pruner

  • Type: Agent context pruning.
  • Purpose: Main. It prunes code observations to reduce context and token use in coding agents.
  • Savings scope: Complete multi-turn benchmark tasks, including agent interactions across turns. The paper reports task-level token consumption, not only the pruned file output. The headline 23–54% range combines different benchmarks and models. A separate single-turn test measures prompt compression only.
  • Baseline and test: The authors compare agents with and without SWE-Pruner on SWE-Bench Verified and SWE-QA. On SWE-Bench Verified, each model was tested on 500 tasks.
  • Token volume: −23.1% to −38.3% task tokens on SWE-Bench Verified. SWE-QA results range from −8.9% to −54.4% across the table's models and repositories.
  • Cost: −26.8% to −36.4% API cost on SWE-Bench Verified. Whether the cost includes the pruner's compute is not clear.
  • Latency: No comparable end-to-end delta found. The paper reports pruner latency separately.
  • Accuracy or quality: +1.2 to +1.4 percentage points in SWE-Bench Verified resolve rate.

Sources: Author paper, sections 4–5; author repository.
