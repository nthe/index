Product research note · survey snapshot 14 Nov 2026

l0-compressor

  • Purpose: Main. The CLI filters command output to reduce the tokens an agent reads.
  • Token volume: −87.8% to −97.1% for six captured noisy command outputs; −96.6% weighted. The project also estimates −50% to −80% for typical mixed sessions.
  • Savings scope: The benchmark compares selected command outputs before and after filtering, not complete agent sessions. Short outputs can pass through. The session estimate uses command-output telemetry, estimates tokens as bytes divided by four, and does not establish total agent-session token savings.
