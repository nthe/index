snip

  • Reduction purpose: Main. snip filters command output to reduce LLM token use.
  • Savings scope: Applicable command output, not all session tokens. Commands with no matching filter pass through unchanged. The project also reports savings across 128 filtered commands in one Claude Code session, but does not compare total session tokens.
  • Token volume: −60% to −90% tool output claimed.
  • Cost: n/a.
  • Latency: n/a.
  • Accuracy or quality: n/a.

The project compares filtered and raw command output. Its 97.1% example compares one go test result, not a complete session. The filter changes the command output format, so the example is not a direct comparison of identical output streams.
