Product research note · survey snapshot 14 Nov 2026

RTK

  • Type: CLI output filtering.
  • Reduction purpose: Main. RTK aims to reduce agent token use through CLI output filtering.
  • Savings scope: Output from supported CLI commands; complete session token and cost savings are not reported.
  • Baseline and test: CLI output before and after filtering; token estimates use output bytes divided by four, not a tokenizer.
  • Token volume: Project claims 60–90% less tool output.
  • Cost: Not reported; project says output reduction is not a cost figure.
  • Latency: Proxy overhead claimed under 10 ms; no end-to-end comparison.
  • Accuracy or quality: Not quantified.

Filtered tool output is only part of total agent tokens; cache billing and extra calls affect cost.

Sources: Product or authors; method or additional source.
