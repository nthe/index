Product research note · survey snapshot 14 Nov 2026

Tanuki Context

  • Reduction purpose: Main. It reduces large context by rendering text as images or storing and retrieving selected parts.
  • Savings scope: The −72% to −94% claim compares selected log payloads as text and images. It is not a complete-session token saving. The estimates use provider image pricing rules. The text estimate is not a billed token count. Retrieval and other messages can change the result.
  • Token volume: −72% to −94% estimated input for selected logs.
  • Cost: In a separate small agent-task test, median cost increased from $0.049 to $0.173 per run (+253%); mean cost fell from $0.392 to $0.175 (−55%). Each arm had nine runs across two tasks. One expensive baseline run affected the mean. The test uses stash and retrieval, not the imaging comparison.
  • Latency: n/a.
  • Accuracy or quality: In a separate image reading test, task success ranged from 0% to 100%, depending on the model; text baselines ranged from 88% to 100%. Tiny text and aggressive distillation reduced task success in another small test. These are separate tests, not accuracy deltas for the full savings range.

Sources: Project documentation; Evaluation and task comparison.
