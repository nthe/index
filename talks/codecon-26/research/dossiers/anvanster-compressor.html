Product research note · survey snapshot 14 Nov 2026

anvanster compressor

  • Purpose: Main. The project aims to reduce token use in coding agents with instructions and tool-output compression.
  • Token volume: −16.1% median context volume for a log-heavy agent task. Context volume includes input, cache-write and cache-read tokens. The comparison uses five live Claude sessions per arm, with the compression hook on versus off and instructions held constant. It is task-session context, not just compressed tool output; it excludes output tokens.
  • Cost: n/a.
  • Latency: n/a.
  • Accuracy or quality: n/a. The project reports 30/30 task successes across the hook benchmark, but no comparative accuracy delta.

The same benchmark reports approximately no context savings on moderate output and a 16.4% increase on dense code. These are small, model-specific samples.

Sources: Project documentation; benchmark method and results.
