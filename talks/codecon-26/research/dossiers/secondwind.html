Product research note · survey snapshot 14 Nov 2026

secondwind

  • Purpose: Main. The product reduces the tokens in agent tool outputs.
  • Savings scope: Individual tool-output blocks from a benchmark corpus. The cache-cost test models a 12-turn conversation; it is not a measured complete agent task. The offload test assumes that the agent does not retrieve the offloaded content.
  • Token volume: −3.0% to −56.1% for inline compression of applicable corpus blocks; −84.8% to −100.0% for recoverable offload. The latter moves content out of the prompt and can require a later retrieval. Neither range is total session savings.
  • Cost: −22.9% modeled input cost for inline compression across the conversation; −64.5% for offload in the stated best case. The offload result excludes retrieval costs and uses a modeled prompt cache.
  • Latency: n/a for end-to-end latency. The project reports compression overhead per block, not a complete agent-task comparison.
  • Accuracy or quality: n/a. The project verifies value recovery; this does not measure task accuracy.

Sources: Project documentation; benchmark and method.
