Product research note · survey snapshot 14 Nov 2026

AI Token Optimization Gateway

  • Type: Caching and model routing gateway.
  • Purpose: Main. The gateway targets LLM cost and token reduction. Compression is one of its strategies.
  • Baseline and test: The repository claims a benchmark with 50 agents over an eight-hour workday. It does not give detailed test methods.
  • Token volume: −74% daily tokens in the claimed multi-agent pipeline benchmark (4.2 million to 1.1 million).
  • Cost: −74% monthly cost in the same claimed benchmark ($1,260 to $330). The headline claims −60% to −80%, but does not specify its test scope.
  • Latency: −85% for cache hits (1,200 ms to 180 ms); this is not a full-workflow latency comparison.
  • Accuracy or quality: Not found in cited source.

The pipeline figures cover the stated multi-agent workload, not a verified complete agent session. Cost reduction through routing or caching does not imply prompt compression. The repository also claims 15–25% reduction for system prompts, without a test baseline.
