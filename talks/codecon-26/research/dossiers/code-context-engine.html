Product research note · survey snapshot 14 Nov 2026

Code Context Engine

  • Type: Code retrieval MCP.
  • Reduction purpose: Main. The project presents token savings as a primary goal of its code retrieval tool.
  • Baseline and test: FastAPI, 20 queries versus reading complete files.
  • Token volume: 83,681 → 4,927 (−94%).
  • Savings scope: Average retrieval tokens per query, not all tokens in a complete agent session. The project also describes the 94% as a per-session saving, but its benchmark measures retrieval against full-file reads, not actual agent behavior. A separate 89% claim compares retrieved chunks before and after chunk compression.
  • Cost: Not found in cited source.
  • Latency: 0.4 ms retrieval p50; no baseline comparison.
  • Accuracy or quality: Recall@10 0.90; no task accuracy.

Full-file baseline does not represent every normal agent workflow.
