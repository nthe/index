Edgee Compress API

  • Purpose: Main for the Compress API. It compresses request payloads; compression is one feature of the broader Edgee gateway. API, gateway.
  • Savings scope: n/a for a measured API comparison. The API returns local input-token counts for each submitted request; tool-result trimming is enabled by default. These counts do not measure a full session or provider billing. The documented 19% reduction is an example, not a benchmark.

These are full benchmark task runs with the gateway, not a direct test of the standalone Compress API. The layers were tested separately.
