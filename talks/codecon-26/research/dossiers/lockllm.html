LockLLM

  • Type: AI security and optimization gateway with optional prompt compression.
  • Reduction purpose: Secondary. The gateway also provides security scanning, routing, and caching. Compression reduces prompt tokens.
  • Baseline and test: The documentation claims savings for submitted prompts. It does not give a benchmark method or a complete-session comparison.
  • Token volume: Vendor claims −30% to −60% for JSON with TOON, and −30% to −70% for text with Compact. The figures cover applicable prompts, not total agent-session tokens. The Compact range depends on its configured rate.
  • Cost: No comparable net cost delta reported. Compact and Combined cost $0.0001 per use in addition to other fees; TOON is free.
  • Latency: No end-to-end delta reported. Compact adds a processing step.
  • Accuracy or quality: Not quantified.
  • Savings scope: Individual eligible prompts or JSON inputs. Complete workflow and session savings are n/a. The documentation does not provide the workload or methods for the claimed ranges.

Sources: LockLLM product; prompt compression documentation.
