LLMLingua-2

  • Type: Prompt compression library.
  • Reduction purpose: Main. The method compresses prompts to reduce inference overhead.
  • Baseline and test: Authors compare compressed and original prompt pipelines.
  • Token volume: 2–5× prompt compression in the latency test. These are test compression settings, not measured savings across a complete agent session.
  • Cost: Not quantified in abstract.
  • Latency: 1.6–2.9× end-to-end speedup for the tested MeetingBank pipeline, including compression and inference. This is not a complete agent-session comparison.
  • Accuracy or quality: No single numerical comparison in abstract.

Model, hardware, and task affect speed and accuracy.
