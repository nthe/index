Product research note · survey snapshot 14 Nov 2026

compressoor

  • Type: Concise runtime policy and prompt scaffold compressor.
  • Reduction purpose: Main. The project aims to reduce token overhead in coding-agent sessions.
  • Baseline and test: Fifteen reusable prompt scaffolds before and after compaction. A separate live Codex run used one prompt.
  • Token volume: −35.8% average prompt tokens with compact; −46.0% with compact_min. The single live run reported about −0.1% total tokens. Its input tokens increased slightly.
  • Cost: Not reported.
  • Latency: Not reported.
  • Accuracy or quality: Not quantified.
  • Savings scope: The primary result covers the selected prompt scaffolds, not complete sessions. The live result covers one run; the project reports no aggregate session benchmark.
