Amazon ElastiCache semantic cache

  • Type: Semantic response cache.
  • Purpose: Secondary. ElastiCache is a general cache service; semantic caching is one use. The semantic-cache use reduces LLM calls, cost, and latency by reusing responses; it does not compress prompts. AWS overview
  • Baseline and test: AWS streamed 63,796 chatbot queries and paraphrases through an initially empty cache and compared results with no cache. This is a query workload, not a complete agent session. AWS benchmark
  • Token volume: No comparative delta reported.
  • Cost: −86.3% for the full tested query workload at a 0.75 similarity threshold. The comparison includes embeddings, LLM inference, and the ElastiCache instance; it excludes ancillary components such as EC2. AWS test method
  • Latency: −88.3% average end-to-end query latency across that workload at the same threshold.
  • Accuracy or quality: 91.2% of cached responses answered the user's intent at that threshold. AWS does not provide a comparable baseline accuracy delta.

The result depends on the query mix, cache hit rate, similarity threshold, and models. It does not establish savings across a complete agent workflow.
