Product research note · survey snapshot 14 Nov 2026

ScaleDown

  • Purpose: Main. The framework reduces LLM token usage through context selection and prompt compression.
  • Savings scope: Individual FinanceBench question-and-document examples, aggregated across one QA benchmark run. The compressor targets the context field. The comparison does not cover a complete agent session or workflow.
  • Baseline: Full context sent to GPT-5.2. The comparison sends compressed context to the same model.
  • Token volume: About −70% downstream input per example, as described by the author; the compression rate is a benchmark setting.
  • Cost: −61% reported across the benchmark run ($18.50 to $7.20). The source does not state whether this includes compressor fees.
  • Latency: n/a.
  • Accuracy or quality: +5.59 percentage points token F1 (0.1989 to 0.2548). The source calls this a 6.5% improvement; that does not match the displayed values.

ScaleBench can measure end-to-end example latency and cost, but its README does not itself provide a matched result. Merge Gateway is a separate integration using a ScaleDown model.

Sources: ScaleDown SDK; author FinanceBench comparison; ScaleBench framework.
