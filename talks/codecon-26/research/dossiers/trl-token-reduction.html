Product research note · survey snapshot 14 Nov 2026

TRL token reduction

  • Type: Retrieval, compression and routing layer.
  • Reduction purpose: Main. The layer reduces token use and cost.
  • Savings scope: The headline figures cover provider-reported input tokens for three individual heavy tasks per model: document QA, one agent turn, and code QA. They do not measure complete agent sessions. Output tokens are excluded. A separate paired agent-loop test sums billed input over all turns; two runs ranged from about 15% lower to 70% higher than a grep-and-read agent. These results use different tasks and baselines.
  • Baseline and test: Three tasks per model; provider usage comparison.
  • Token volume: GPT-5.5 input 16,875 → 2,232; Opus 26,573 → 3,343.
  • Cost: Not found in cited source.
  • Latency: Not found in cited source.
  • Accuracy or quality: 3/3 versus 3/3 for each model.

Very small samples cannot establish equivalence.
