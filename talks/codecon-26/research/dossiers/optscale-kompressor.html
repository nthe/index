OptScale Kompressor

  • Type: Coding-agent compressor.
  • Reduction purpose: Main. Compression is also a feature of the broader OptScale AI platform.
  • Savings scope: The −25% input and −22.7% cost figures cover complete benchmark agent task runs, not only compressed tool outputs. The analysis covers the 87 tasks that all test arms completed; it excludes some failed setup trials and seven compressor trials with a streaming defect. The input figure excludes output tokens. A separate −62.8% claim covers characters in eligible tool outputs replayed offline.
  • Baseline and test: Terminal-Bench 2.1, Codex and GPT-5.5 versus no compression; vendor test. Cost includes provider prompt-cache discounts.
  • Token volume: 25% less prompt traffic.
  • Cost: Bill $107.89 → $83.40 (−22.7%).
  • Latency: Not found in cited source.
  • Accuracy or quality: Authors report no significant solve-rate change.

Details and limitations: Vendor benchmark and methods.
