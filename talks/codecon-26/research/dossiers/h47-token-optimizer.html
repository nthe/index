h47 token optimizer

  • Type: Local prompt compression.
  • Purpose: Main. The product compresses LLM prompts.
  • Baseline and test: Project examples compare individual inputs with their compressed versions. The token counts are estimates.
  • Token volume: Claims 70–97% fewer prompt tokens for long or repetitive inputs.
  • Cost: Not found in cited source.
  • Latency: Not found in cited source.
  • Accuracy or quality: Not found in cited source.

The claim covers individual compressed inputs, not a complete agent session or workflow. The project reports 0% compression for a short prompt. Its token estimator uses character and word counts, not a model tokenizer. End-to-end session savings are not reported.

Sources: Product and benchmark; token estimate limitations.
