Microsoft TokenEconomizer

  • Reduction purpose: Main goal is coding-agent cost control. It reduces waste through reusable facts, tool pruning, and loop intervention. It is not a prompt compressor.
  • Savings scope: Full benchmark task sessions across 277 SWE-bench tasks and five agent–model combinations. Each task is one session. The cost includes the plugin’s model calls and cache pricing. It is an average across tasks, not a per-message reduction.
  • Token volume: n/a.
  • Cost: −18.4% to −30.9%.
  • Latency: n/a.
  • Accuracy or quality: −1.0 to +2.6 pp Pass@1.
