Product research note · survey snapshot 14 Nov 2026

SigMap

  • Type: Code context retrieval.
  • Reduction purpose: Main. SigMap gives coding agents compact code signatures to reduce context tokens.
  • Baseline and test: For 51 tasks, compare whole-repository source with files ranked by SigMap. A separate scale test compares source with signatures for 321 supported repositories. A Devin A/B test measures agent time.
  • Savings scope: The token and estimated cost figures cover retrieved task context, not all messages or tokens in a complete agent session. The scale figure covers repository content. The separate Devin test measures task time, not session token or cost savings.
  • Token volume: −99.2% task context; −98.7% aggregate repository content in the scale test.
  • Cost: About −99% estimated for task context (96× cheaper); total session cost not reported.
  • Latency: 8.4 versus 8.0 min in three repetitions; no speedup established.
  • Accuracy or quality: Not established in headline.

The project retracts its earlier speedup claim in the results. The token, cost, and timing figures use different tests.

Sources: Product repository; author benchmark report.
