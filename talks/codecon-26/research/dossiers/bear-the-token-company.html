Product research note · survey snapshot 14 Nov 2026

Bear / The Token Company

  • Type: Prompt compression API.
  • Reduction purpose: Main. Bear is a prompt compression product. Product.
  • Savings scope: The 50% token target and TTFT comparison apply to each compressed transcript and the resulting model request. They do not measure a complete agent session. The separate finance test measures question-answering pipelines over filings, not agent sessions. Latency test; finance test.
  • Baseline and test: Vendor test: direct model API versus compression then same model, 33 transcripts; 10 runs per configuration.
  • Token volume: About 50% input at fixed ratio.
  • Cost: Not quantified in this latency test.
  • Latency: Up to 49% lower end-to-end TTFT at 200k tokens; some models do worse.
  • Accuracy or quality: Not measured in latency test. In a separate finance QA test, Claude Haiku 4.5 scored +0.2 percentage points on readable filings at 50% retention, compared with full filings; Gemini scored −0.3 points over all 150 questions. The previously recorded +2.7-point claim could not be verified in the available source.

Latency and accuracy numbers use different experiments. Compression API charges and cache effects need separate accounting.

Sources: Product or authors; finance benchmark.
