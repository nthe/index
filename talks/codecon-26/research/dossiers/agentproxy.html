Product research note · survey snapshot 14 Nov 2026

AgentProxy

  • Type: Agent tool-output proxy.
  • Purpose: Main. The proxy compresses agent tool results to reduce token use.
  • Baseline and test: 30 SWE-bench tasks with GPT-5-nano versus no proxy.
  • Savings scope: The reported token reductions cover total prompt and completion tokens across the 30 agent task runs, with up to 30 turns per task. They are not limited to compressed tool outputs. The proxy primarily changes tool results; results depend on the agent and workload. Benchmark method
  • Token volume: Input −24.9%; output −16.9%.
  • Cost: Not found in cited source.
  • Latency: About 0.2 ms compression overhead; no end-to-end comparison.
  • Accuracy or quality: Patches generated 10/30 → 14/30. The benchmark method uses --skip-eval; patch generation does not establish task success.

Small sample; no proof of improved accuracy.
